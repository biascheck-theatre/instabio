# InstaBio

Link-in-bio landing page for **Bias Check Theatre**.

## Live site

After GitHub Pages is enabled, the site will be available at:

**https://biascheck-theatre.github.io/instabio/**

## Enable GitHub Pages (one-time)

Sign in to GitHub as **biascheck-theatre**, then:

1. Open [github.com/biascheck-theatre/instabio/settings/pages](https://github.com/biascheck-theatre/instabio/settings/pages)
2. Under **Build and deployment** → **Source**, select **Deploy from a branch**
3. Set **Branch** to `main` and folder to `/ (root)`
4. Click **Save**

Deployment usually takes 1–2 minutes. Refresh the Pages settings page to see the live URL.
